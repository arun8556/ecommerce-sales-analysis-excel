# E-commerce Sales Analysis | Excel

## 1. Project Overview

An Excel-based sales analysis project focused on evaluating e-commerce business performance, identifying sales trends, and understanding factors influencing profitability.

## 2. Project Objectives

- Evaluate overall sales and order performance.
- Analyse Average Order Value (AOV) trends.
- Investigate product category performance.
- Understand factors influencing business profitability.
- Identify data quality issues affecting analysis.

## 3. Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Pivot Charts

## 4. Project Workflow

1. Dataset inspection and understanding.
2. Data validation and quality checks.
3. Investigation of anomalies in profit margin values using reverse calculation.
4. Exploratory Data Analysis (EDA).
5. Sales and profitability analysis.
6. Dashboard development.

## 5. Data Validation & Quality Checks

- Investigated unusually high profit margin values.
- Applied reverse calculation to examine the relationship between profit margin, shipping cost, and total amount.
- Investigated category-level margin patterns to understand the underlying calculation logic.

## 6. Key Business Findings

- Average Order Value (AOV) declined despite an increase in order volume.
- Order distribution shifted towards low- and mid-value transactions.
- Higher sales volume did not necessarily translate into higher profitability.
- The North region recorded a comparatively high return rate, highlighting an area for further investigation.

## 7. Project Structure

- **Dataset:** Original dataset.
- **Ecommerce_Sales_Analysis.xlsx:** Workbook containing data validation, analysis, business story and dashboard.
- **Dashboard-Screenshots:** Visual representation of the completed dashboard.

## 8. Conclusion

This project demonstrates an Excel-based analytical workflow, from data inspection and validation to exploratory analysis, business insights, and dashboard reporting.
